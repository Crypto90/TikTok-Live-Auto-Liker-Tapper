# 🚀 TikTok Live Auto Liker v1.2.4

Fixes the Multi-Stream Grid View toggle so you can always switch back to the normal tabbed view.

---

## 🌟 What's New in v1.2.4

### 🔲 Grid View No Longer a Dead End
- The **⊞ Grid View / 📑 Tab View** button used to live on the tab bar's corner, which is exactly the part of the window that gets hidden once Grid View is active — so once you switched to Grid View, there was no button left to switch back.
- The toggle now sits in its own bar above the stream view, so it stays visible and clickable in both Tab View and Grid View.
